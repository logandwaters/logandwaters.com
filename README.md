# The Personal Site of Logan Waters

The source for [logandwaters.com](https://logandwaters.com), my personal site and portfolio. It introduces my work, projects, current interests, and background as I make my way into web development and will continue to evolve with me.

## Architecture

The site is built with Astro and generated as static pages. Astro components provide the page structure, with custom CSS for the design and small browser-side scripts for features like the theme switcher. The built site can be served without an application server.

## Run a local version

With Node.js and npm installed:

```sh
npm install
npm run dev
```

Some elements are derived at build time. To generate and preview the static site:

```sh
npm run build
npm run preview
```
