Project / Open-source developer tools

Toolgek: small tools,
clear purpose.

Toolgek is an independent project exploring a straightforward way to define, run, present, and document browser-based developer utilities.

The idea

Each tool is a self-describing JavaScript package that brings together its implementation, manifest, interface information, and documentation.

The approach

Keep utilities focused, execute transformations in the browser where possible, and make the underlying packages inspectable and reusable.

My role

Product direction, architecture, interface design, development, and the systems that connect the packages to the platform.

What I'm learning

How to make a coherent developer experience from small utilities, and how to validate and grow an independent product.
